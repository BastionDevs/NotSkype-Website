Getting started

Before you begin: NotSkype is still in beta. We recommend using a password that you do not use elsewhere, and only download clients or patchers from us directly.
  1. Create an account
    Sign up for a NotSkype account. One account works for all apps supported by NotSkype.
  2. Download a client
    We provide both pre-patched and unpatched versions of officially supported clients on our downloads page.
  3. Install and patch
    Pre-patched clients already provide modified client files to connect to our service.
    Unpatched clients are unmodified versions from the original developers, requiring manual patching to use our service.
  4. Sign in and Enjoy!
    Use your NotSkype account credentials to sign in to the clients. Some clients require enabling insecure access, which can be done from your account portal.

If sign-in fails

  • Confirm that you have entered correct credentials.
  • Ensure you have patched the clients to connect to our service.
  • Check service status for known outages or maintenance.
  • If using Windows XP/Vista/older, modern TLS/certificate requirements can cause failures even when the messenger itself is compatible.

What to include in a bug report

  • Exact version/build of client
  • Windows version
  • Steps you did that caused the error
  • Error code, message or screenshot
  • Relevant client logs
